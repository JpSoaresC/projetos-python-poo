# portfolio-python-oop
Portfolio de códigos voltados a OOP em Python

# Motor de Validação de Regras de Negócio com Descritores (Projeto Acqua Park - Mate Academy).

Fiz a implementação de um sistema de validação robusto utilizando Descritores Python (__get__, __set__, __set_name__)para garantir a integridade de tipos e intervalos de dados(idade, peso, altura).
Uso de tratamento de exceções (try/except) para falhas silenciosas e seguras, como pedem as boas práticas.

Tecnologias utilizadas: Python, Programação Orientada a Objeto, Tratamento de Exceções, Git.

# Arquitetura de Entidades com Padrões de Projeto OOP (Projeto Elves and dwarves - Mate Academy)

Fiz a modelagem de um sistema de personagens utilizando classes abstratas (ABC), Herança Multinível e Polimorfismo.
A estruturação do código foi feita em módulos e pacotes (separação de responsabilidades).
Além da implementação de métodos mágicos para cálculo dinâmico de atributos.

Tecnologias: Python, Orientação a Objetos, Git.
