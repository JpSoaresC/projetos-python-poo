# Calculadora de Consumo Energético Residencial (Em andamento)

## Sobre o Projeto
Aplicação de linha de comando desenvolvida em Python para auxiliar pequenos empreendedores e residências no controle e economia de energia elétrica. O sistema permite o cadastro de eletrodomésticos e calcula automaticamente o impacto financeiro e energético de cada um, gerando um relatório completo para tomada de decisões.

## Funcionalidades (Até o momento)
- **Cadastro de Aparelhos:** Registro de nome, potência (Watts), horas e dias de uso.
- **Cálculo Automático:** Conversão de potência para consumo mensal em kWh.
- **Estimativa de Custos:** Cálculo do valor em Reais (R$) baseado na tarifa de energia.
- **Classificação de Consumo:** Sistema de etiquetas (Baixo, Médio e Alto Consumo) para identificar vilões da conta de luz.
- **Relatório Gerencial:** Saída formatada no console com o consumo e custo total do estabelecimento.

## Tecnologias Utilizadas (Até o momento)
- Python 3
- Programação Orientada a Objetos (POO)
- Lógica de Programação e Estruturas de Dados
